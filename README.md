## Реализация

### Особенности CUDA

В отличие от CPU-реализаций (OpenMP, MPI), CUDA позволяет задействовать тысячи лёгких потоков на GPU, что нам и надо для такой простой задачи. Основные этапы:

1. Генерация матриц на хосте (CPU).
  
2. Копирование матриц в память устройства (GPU).
  
3. Запуск ядра (kernel) с заданной конфигурацией сетки блоков и нитей.
  
4. Копирование результата обратно на хост.
  
5. Замер времени.
  
  ### Генерация матриц и проведение замеров
  
  ```cpp
  int main() {
   const int sizes[] = {200, 400, 800, 1200, 1600, 2000};
   const int repeats = 3;
  
   BlockConfig configs[] = {
       {8, 8, "8x8"}, {16, 16, "16x16"}, {16, 32, "16x32"},
       {32, 16, "32x16"}, {32, 32, "32x32"}
   };
  
   for (int n : sizes) {
       Matrix A = generate_matrix(n), B = generate_matrix(n);
       for (auto cfg : configs) {
           dim3 threads(cfg.tx, cfg.ty);
           dim3 blocks((n+threads.x-1)/threads.x, (n+threads.y-1)/threads.y);
  
           double total = 0.0;
           for (int r = 0; r < repeats; ++r) {
               cudaEvent_t start, stop;
               cudaEventCreate(&start);
               cudaEventRecord(start);
               
               matmul_kernel<<<blocks, threads>>>(d_A, d_B, d_C, n);
               cudaEventRecord(stop);
               cudaEventSynchronize(stop);
               float ms;
               cudaEventElapsedTime(&ms, start, stop);
               total += ms / 1000.0;
           }
           double avg = total / repeats;
           // запись в CSV: n, cfg.name, avg
       }
   }
  }
  ```

## Анализ результатов

Самый простой случай 8х8 для 2000 матрицы показывает результат меньше десятой секунды. Фантастический результат, с учётом того, что самый лучший вариант на CPU нагружал процессор до 100% и даже такполучалось едва меньше 10 секунд, в то время как моя ноутбучная GTX 1660 ti даже не почувствовала никакой нагрузки.

Судя по графикам наилучший прирост происходит при увеличении блока с 8х8 до 16х16, далее для такой просто задачи, прирост не так ощутим.
